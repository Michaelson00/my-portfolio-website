Equinox font
============

Place your Equinox font file(s) in this folder. The CSS looks for these
file names, in order:

  1. Equinox.woff2
  2. Equinox.woff
  3. Equinox.otf
  4. Equinox.ttf

You only need one of them — woff2 is smallest and loads fastest.
If the font is not found, the site falls back to Syne (loaded from
Google Fonts) and then to the system UI font.
