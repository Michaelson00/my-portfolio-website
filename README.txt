Put your Equinox font file in this folder.

Name it one of these (the site tries them in this order):
  Equinox.woff2
  Equinox.woff
  Equinox.otf
  Equinox.ttf

Check the licence of the Equinox font you download. Many free copies are for
personal use only, and a public portfolio may count as commercial use.

If no file is here, the site shows the stand-in font Syne for headings.
Nothing else needs changing: styles.css already points at this folder.
